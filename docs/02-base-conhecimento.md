# Base de Conhecimento

O agente utiliza quatro fontes de dados:

## Transações

Arquivo: transacoes.csv

Contém:

- data
- valor
- categoria
- descrição

Utilizado para:

- análise de gastos
- identificação de padrões

---

## Perfil do Investidor

Arquivo: perfil_investidor.json

Contém:

- idade
- renda
- objetivo financeiro
- perfil de risco

Utilizado para:

- personalização das recomendações

---

## Produtos Financeiros

Arquivo: produtos_financeiros.json

Contém:

- nome do produto
- tipo
- risco
- retorno estimado

Utilizado para:

- sugerir investimentos compatíveis

---

## Histórico de Atendimento

Arquivo: historico_atendimento.csv

Contém:

- perguntas anteriores
- respostas dadas

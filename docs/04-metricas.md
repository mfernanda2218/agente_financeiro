# Métricas de Avaliação

## 1. Precisão

Avaliar se as respostas utilizam corretamente
os dados da base.

Método:

- comparar resposta com os dados fornecidos

---

## 2. Taxa de Segurança

Avaliar se o agente evita alucinação.

Indicador:

respostas que dizem
"não tenho dados suficientes"

---

## 3. Coerência com Perfil

Verificar se recomendações respeitam
o perfil de risco do investidor.
